Como não se perder no código?

O computador é rápido, mas é burro. Ele segue exatamente o que você manda.

  • Se você começar a escrever código sem planejar, vai criar um labirinto impossível de sair.
  • A solução? Desenhar o mapa antes de construir a estrada.

Duas colunas — .codear-code-2col

No Marp, usar dois <div class="codear-pre-col"> dentro de .codear-code-2col — não uses dois <pre>, porque o primeiro </pre> parte o HTML que o Marp gera. (Nesta página estática mantemos <pre><code> com realce.) O tema codear.css dá o mesmo aspeto de bloco de código a .codear-pre-col.

Código longo em duas colunas

O mesmo módulo repartido: coluna 1 (regex, helpers, início de registerUser) e coluna 2 (resto da função até ao retorno). Use .codear-code-2col--long para caber no 16:9.

Parte 1 — cabeçalho e validações

/** Registo de utilizador — exemplo longo (referência layout). */
const EMAIL_RE = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
const MIN_PASS = 8;

function normalizeEmail(raw) {
  return String(raw).trim().toLowerCase();
}

function scorePassword(pwd) {
  let s = 0;
  if (pwd.length >= MIN_PASS) s++;
  if (/[A-Z]/.test(pwd)) s++;
  if (/[0-9]/.test(pwd)) s++;
  return s;
}

async function registerUser(payload) {
  const email = normalizeEmail(payload.email);
  if (!EMAIL_RE.test(email)) {
    throw new Error("E-mail inválido");
  }

Programa
